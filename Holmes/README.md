# 雾都道尔探案集

这是一个以福尔摩斯式侦探为原型、但角色与案件均为原创的漫画/绘本脚本项目。

## 项目定位

- 形式：漫画、绘本、儿童推理短篇
- 气质：雾都、观察力、温暖悬疑、轻量系列伏笔
- 读者：儿童可读，成人也能看出推理趣味
- 主角：夏洛克·道尔，一位敏锐、古怪、喜欢小提琴和显微镜的年轻侦探
- 搭档：温斯顿医生，温和可靠的记录者
- 少年伙伴：艾达·贝尔，聪明勇敢，适合承担读者视角和行动推进

## 文件结构

- `SERIES_BIBLE.md`：系列设定、角色、风格规则、长期伏笔
- `scripts/01_雾都钟声里的蓝色羽毛.md`：第一案完整脚本
- `scripts/02_会眨眼的石狮子.md`：第二案完整脚本
- `scripts/03_不会唱歌的夜莺.md`：第三案完整脚本
- `scripts/04_第一个音符落下的地方.md`：第四案完整脚本，初步进入闭眼会主线
- `scripts/05_旧河门下的铜钥匙.md`：第五案完整脚本，取得第一把睁眼钥匙
- `STORY_TIMELINE.md`：当前正文与后续主线的剧情时间线
- `60_CHAPTER_OUTLINE.md`：60 章正文故事总纲

## 使用方式

每个案件都可以独立改编为 16 到 20 页漫画或绘本。分镜脚本中的“画面”“对白”“旁白”可以直接交给绘者继续拆格，也可以继续扩写成更细的页格脚本。

新增脚本时，必须在 `## 主要角色` 中原样写入夏洛克·道尔、温斯顿医生、艾达·贝尔三条固定外貌美术设计提示词，保持所有脚本完全一致。
