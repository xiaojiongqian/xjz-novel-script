# Artifact Contract

Use this reference when initializing or rebuilding a serialized comic or picture-book series. Adapt filenames and language to the user's project, but keep the responsibilities separate.

## Required Beginner Guide

Create one Chinese project-root usage guide following `usage-guide.md`. Prefer `00_使用说明.md` for new projects. For an existing numbered suite, do not renumber established files merely to insert it; add a clearly named guide and link it from the overview.

## Default Shared Project Suite

### 00 — Project Overview and Index

Record the intake result, explicit comic/picture-book form verdict, project charter, one-sentence premise, audience, tone, production-unit format, source hierarchy, file index, establishment status, and unresolved decisions. This is the navigation layer, not a duplicate of every other file.

### 01 — World Bible

Define time and region, daily-life baseline, world history, factions, technology, supernatural rules, costs, prohibitions, public knowledge, major objects, primary locations, and causal limits. Every rule should either enable story or prevent a continuity failure.

### 02 — Series and Season Outline

Define the series promise, season or book-cycle spine, act structure, production-unit disturbance/core event/change/residue, fragment or objective accounting, character-arc milestones, reveals, and future seeds. Distinguish locked episodes/books from candidate ideas.

### 03 — Character and Art Bible

For each important character record canonical identity, narrative role, arc, voice, knowledge boundary, face, hair, proportions, silhouette, costume, palette, asymmetry, props, expressions, relationships, fixed anchors, and prohibitions. Important mascots and non-human companions require the same narrative and visual discipline as human leads.

### 04 — Character Image-Prompt Library

Create a shared style prefix, one complete prompt and one compact prompt per important character, fixed anchors, negative prompt, group-composition rules, and a visual-consistency checklist. Avoid artist-name imitation when an original style description is sufficient.

### 05 — Continuity and Creation Rules

Create the authoritative name table, setting hard rules, episode or book formula, knowledge boundaries, object/count ledger, power checks, voice guide, visual continuity, theme boundaries, change-control rules, and delivery checklist.

### 06 — Primary Location Prompt Library

Cover every major recurring location with a shared style system, full and compact prompts, fixed visual anchors, camera modules, negative prompts, and consistency checks. Primary locations are series-level geography, not every room that appears.

### 07 — Secondary Location Prompt Library

Group detail spaces beneath their primary location. Put the shared style prefix first; use numbered parent locations and restart child numbering inside each parent. Store reusable static spaces here. Keep one-off anomaly or destruction states separate unless the user explicitly requests them.

### Format-Specific Production Templates

Create only the active script template matching the locked form, plus a matching report template. Comics use pages and panels. Picture books use pages or spreads with final text, concise picture intent, and page-turn function. Do not create finished episodes or books unless requested.

### Canon Change Log

Record date, approved change, old value, new value, affected artifacts, deprecated terms, scripts intentionally preserved, and future checks. Keep it concise and factual.

## Completion Levels

- **Foundation ready**: intake verdict, Chinese usage guide, charter, world, season/book-cycle spine, important characters, continuity rules, and the active production templates are coherent.
- **Art ready**: character and location visual systems have executable prompts and drift anchors.
- **Production ready**: all foundation and art checks pass; episode templates and post-episode reporting are active.

Do not label a project production-ready when only prose planning is complete.
