# Comic and Picture-Book Production Formats

Use this reference when creating or auditing script and report templates. World, outline, character, visual, prompt, location, and canon artifacts use the same establishment logic for both forms. The main branch occurs at the script template.

## Comic series

Use page and panel units. Include only fields the user needs for production. A concise default panel contains location, essential visual action, dialogue or caption, and sound effect when needed. Lock page count, approximate panel density, reading level, and script language in the charter.

```markdown
# Episode [N] — [Title]
## Page [N]
### Panel [N] — [Canonical location]
- Visual:
- Dialogue/Caption/SFX:
```

Do not use this template for picture books merely because the book contains sequential action.

## Picture-book series

Use the user's chosen page or spread as the planning unit. Keep the script intentionally simpler than a comic script. The default unit contains manuscript text, a concise illustration intention, and an optional page-turn function. Do not subdivide into panels, prescribe every camera angle, or repeat character-model details already governed by the art bible.

```markdown
# Book [N] — [Title]
## Book-level target
- Emotional arc:
- Canon objective:
- Word budget:
- Page/spread count:

## Spread [N] — [Canonical location]
- Text: [Final reader-facing words; write “Wordless” when intentional.]
- Picture: [Essential visible action, emotion, and story information only.]
- Page turn: [Question, surprise, rhythm, or “None”.]
```

If single pages are the production unit, replace `Spread` with `Page`. A spot vignette is part of one page/spread composition unless the user explicitly requests comic panels.

## Picture-book pacing gate

- The complete text stays within the locked word budget.
- Page turns create a readable rhythm rather than cutting sentences accidentally.
- Text and image complement each other; illustration notes do not merely restate every word.
- Essential actions are visible, but composition remains flexible enough for the illustrator.
- Each book reaches its promised emotional closure while preserving only approved series hooks.
- Wordless pages and repeated refrains are intentional and recorded.
- Character, prop, and location continuity still follow the shared bibles.

## Reports

Use the same continuity responsibilities for both forms. A comic report may use episode and page/panel coverage. A picture-book report uses book and page/spread coverage. In both cases list every appearing character, every shown location, mainline progress, confirmed changes, and open loops.
