# Artifact Templates

Use these skeletons as adaptable heading contracts. Translate headings and rename files to match the user's language and conventions. Remove instructional placeholders from final artifacts.

## Project overview

```markdown
# [Series Title] — Project Overview

## Project Charter
## One-Sentence Premise
## Audience and Format
## Tone and Content Boundaries

## Unresolved Decisions
```
